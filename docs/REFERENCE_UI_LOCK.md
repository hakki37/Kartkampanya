# Kart Kampanya — Reference UI Lock

Bu dosya tasarım sözleşmesidir. İşlev kodu değiştirilebilir; referans UI kuralları korunur.

## Sabit görsel dil
- Açık arka plan: `#F8F7FC`
- Ana mor: `#6D3DF5`
- Koyu mor: `#5B21B6`
- Açık mor yüzey: `#EDEAF7`
- Kenarlık: `#E5E1EF`
- Ana metin: `#211D2D`
- İkincil metin: `#777187`
- 16px yuvarlatılmış inputlar
- Yumuşak, beyaz kartlar ve mor vurgu
- Mor gradient marka alanları

## Ekran sözleşmesi
1. Giriş/Kayıt: logo, uygulama adı, alt açıklama, Giriş Yap/Kayıt Ol sekmeleri, e-posta/şifre, ana mor buton.
2. Ana Sayfa: üst marka alanı, arama, Tümü/Bana Uygun/Favoriler/Son Eklenen filtreleri, kampanya bannerı, kategori kutuları ve kampanya kartları.
3. Bendeki Kartlar: beyaz/mor kart listesi, ekleme butonu ve gerçek seçimli kart ekleme formu.
4. Kategoriler: renkli yuvarlatılmış kategori kutuları ve ikonlar.
5. Alt navigasyon: açık yüzey, mor seçili durum, sabit düzen.

## Kural
Yeni özellik eklenirken bu görsel sözleşme değiştirilemez. Tasarım değişikliği ancak bilinçli bir referans revizyonu olarak yapılır.
